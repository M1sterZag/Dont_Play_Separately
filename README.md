## ⚡ Особенности

### 🔐 JWT Аутентификация
| Действие | Описание |
|----------|----------|
| **Вход** | Пользователь получает `access_token` (1 час) и `refresh_token` (7 дней) |
| **Использование** | `access_token` передается в заголовке `Authorization: Bearer {token}` |
| **Обновление** | `refresh_token` позволяет получить новый `access_token` |
| **Выход** | Токены добавляются в черный список в Redis |
| **Хранение** | `refresh_token` хранится в Redis для возможности отзыва |

### 🎮 Работа с IGDB API
| Этап | Действие |
|------|----------|
| **1** | При первом запросе к игре/платформе → запрос к IGDB |
| **2** | Результат сохраняется в PostgreSQL (кэш) |
| **3** | Дальнейшие запросы к БД, IGDB используется только при обновлении |
| **4** | Redis используется как кэш второго уровня (TTL 24 часа) |
| **5** | Фоновый воркер обновляет устаревшие данные раз в сутки |

## 🗄️ Схема базы данных

### 📊 Структура таблиц

#### 👤 Users (Пользователи)
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `UUID` (PK) | Уникальный идентификатор пользователя |
| `version` | `INT` | Версия для оптимистичной блокировки |
| `email` | `TEXT` (UNIQUE) | Email пользователя |
| `hashed_password` | `TEXT` | Хэшированный пароль (bcrypt) |
| `nickname` | `TEXT` (UNIQUE) | Отображаемое имя |
| `bio` | `TEXT` | Информация о пользователе |
| `favorite_platform_id` | `UUID` | Любимая платформа (FK → Platforms) |
| `avatar_url` | `TEXT` | Ссылка на аватар |
| `created_at` | `TIMESTAMP` | Дата регистрации |

---

#### 🎯 Teams (Команды/Лобби)
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `UUID` (PK) | Уникальный идентификатор команды |
| `version` | `INT` | Версия для оптимистичной блокировки |
| `owner_id` | `UUID` (FK → Users) | Создатель команды (капитан) |
| `game_id` | `UUID` (FK → Games) | ID игры из кэша |
| `platform_ids` | `INT[]` | Массив ID платформ из IGDB |
| `title` | `TEXT` | Заголовок объявления |
| `description` | `TEXT` | Подробное описание |
| `is_rating_required` | `BOOL` | Требуется ли рейтинг |
| `desired_rating` | `TEXT` | Желаемый ранг/рейтинг |
| `contact_link` | `TEXT` | Ссылка для связи |
| `slots_total` | `INT` | Общее количество мест |
| `created_at` | `TIMESTAMP` | Дата создания |
| `expires_at` | `TIMESTAMP` | Дата автоматической деактивации (по умолчанию +7 дней) |
| `is_active` | `BOOL` | Активна ли команда |

> **ℹ️ Примечание:**
> - `expires_at` автоматически устанавливается при создании команды (created_at + 7 дней)
> - `is_active` становится `false` при достижении `expires_at`
> - `platform_ids` хранит ID из IGDB (например, `[48, 6]` = PS5, PC)

---

## 🔌 API Эндпоинты

### 🔐 Auth and Users

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `POST` | `/api/v1/auth/register` | Регистрация нового пользователя |
| `POST` | `/api/v1/auth/login` | Вход в систему |
| `POST` | `/api/v1/auth/refresh` | Обновление access токена |
| `POST` | `/api/v1/auth/logout` | Выход из системы |
| `GET` | `/api/v1/users/profile` | Получение профиля текущего пользователя |
| `PUT` | `/api/v1/users/profile` | Обновление профиля |
| `POST` | `/api/v1/users/profile/change-password` | Смена пароля |

---

### 🎯 Teams

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `POST` | `/api/v1/teams` | Создание новой команды |

| `GET` | `/api/v1/teams/{team_id}` | Получение команды по ID |
| `PUT` | `/api/v1/teams/{team_id}` | Редактирование команды |
| `DELETE` | `/api/v1/teams/{team_id}` | Удаление команды |

### 📊 Параметры фильтрации

#### GET `/api/v1/teams`
| Параметр | Тип | Описание |
|----------|-----|----------|
| `game_id` | `UUID` | Фильтр по ID игры |
| `platform_id` | `INT` | Фильтр по ID платформы (IGDB) |
| `limit` | `INT` | Количество записей на страницу (по умолчанию 20) |
| `offset` | `INT` | Смещение для пагинации |

#### GET `/api/v1/games`
| Параметр | Тип | Описание |
|----------|-----|----------|
| `search` | `STRING` | Поиск по названию игры |
| `limit` | `INT` | Количество записей (по умолчанию 10) |
